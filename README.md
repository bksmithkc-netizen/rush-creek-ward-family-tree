# Rush Creek Ward — Family Tree Review

A free family-tree error checker for any member of the Church.

Upload a GEDCOM file (or paste family info) and get an instant report of likely
problems in your tree: impossible or missing dates, missing temple ordinances,
duplicate individuals, incomplete names, and marriage/family errors.

- **Runs entirely in your browser.** No data is uploaded or stored anywhere.
- **8 languages** — English, Spanish, Portuguese, French, German, Tagalog, Samoan, Japanese.
- **Scan 1–20 generations back**, with individual checks you can turn on or off.

Built for the Rush Creek Ward.
